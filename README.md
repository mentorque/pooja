# Pooja Neeralagi — Professional HR Portfolio

Modern, interactive portfolio website for **Pooja Neeralagi** — HR Administrator & People Operations Specialist based in Dublin, Ireland. Associate Member of CIPD (Level 5) with an MSc in Human Resource Management and IPASS Certificate in Payroll Techniques (QQI Level 6, in progress).

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Vanilla CSS Modules
- **Animations & Interactivity**: Framer Motion, 3D Tilt Card Engine, Lucide Icons, Radix UI

## Features
- **Hero Section**: 3D interactive tilt profile card, dynamic rotating role highlights, Dublin location badge, direct resume download, and quick contact buttons.
- **Work Experience**: Structured career timeline covering end-to-end recruitment, employee lifecycle management, GDPR compliance, Irish payroll support, and retail operations.
- **Key HR Initiatives**: Showcase of practical implementations including IPASS QQI Level 6 Irish payroll models, international talent sourcing pipelines, and GDPR audit systems.
- **Skills & Expertise**: Categorized competencies across HR Admin, Recruitment, Irish & UK Employment Law, Payroll (PAYE/PRSI/USC), and Advanced Excel.
- **Education & Mentorship**: MSc Human Resource Management (Aston University, UK), BBA International Business (Jain University), and student mentorship initiatives.
- **Professional Certifications**: Verified credentials from IPASS (QQI Level 6), CIPD (Assoc CIPD Level 5), and IIM Kozhikode / UpGrad.
- **Contact & Footer**: Direct links for Email, Phone (+353 89 941 7297), LinkedIn, and CV download.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
